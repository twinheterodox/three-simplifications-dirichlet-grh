# Three simplifications in the Alpöge–Claude argument for Dirichlet GRH

twinheterodox · 21 November 2026

[Read the ten-page paper](output/pdf/three-simplifications-dirichlet-grh.pdf)

How can an upper bound for a prime sum, available only on selected intervals, rule out a zero of a Dirichlet L-function? The paper follows one centered prime sum from a lattice inequality to a zero-free criterion. The main result compares the character sums at a common scale and allows more variation in their weights while preserving the exponent in the upper bound. Two accompanying arguments remove a logarithmic loss from the lattice estimate and handle a possible real zero using an oscillation theorem. The construction of the theta lifts and the estimates producing the intervals are inputs.
